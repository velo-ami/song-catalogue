# Song Catalogue - C Programming

A command-line song catalogue application developed in C to practise fundamental programming concepts, data organisation and file handling.

## Features

- Add songs with artist, title, price and release year.
- Save song records to a text file (`songs.txt`).
- Load previously saved songs.
- Display songs sorted by release year, newest first.
- Store up to 50 songs.

## Technologies

- **Language:** C
- **Libraries:** stdio.h, stdlib.h, string.h
- **Concepts:** Structures, arrays, functions, loops, file I/O and bubble sort.

## How to Run

Clone or download the repository, then open a terminal in the project folder.

Compile the program:

```bash
gcc main.c -o main
```

Run it:

```bash
./main
```
